---

Download **`MojeKocky-Setup-….exe`** below under **Assets** and run it. Windows 10 and 11 (64-bit), no admin rights needed. The [README](https://github.com/jakubmatisak/moje-kocky-desktop#english) describes what the app does; older versions are under [Releases](https://github.com/jakubmatisak/moje-kocky-desktop/releases).

A new version installs over the old one. Your data in `%APPDATA%\MojeKocky` stays, and before the first start of the new version the database is backed up into `%APPDATA%\MojeKocky\backups` ([how to restore a backup](https://github.com/jakubmatisak/moje-kocky-desktop#backup-on-update)).

The installer is not code-signed. When Windows says "Windows protected your PC", click **More info → Run anyway**. If Windows says it cannot access the file, your antivirus blocked the program: Windows Security → Protection history → Allow on device.

Project website: https://jakubmatisak.github.io/moje-kocky/

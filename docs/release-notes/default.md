Download **`MojeKocky-Setup-….exe`** below under **Assets** and run it. Windows 10 and 11 (64-bit). The installer asks for administrator rights and installs the program into Program Files for every user of the PC; each user has their own data in `%APPDATA%\MojeKocky`. The [README](https://github.com/jakubmatisak/moje-kocky-desktop#english) describes what the app does; older versions are under [Releases](https://github.com/jakubmatisak/moje-kocky-desktop/releases).

Prices are estimates from the services (BrickEconomy), not investment advice. LEGO® is a trademark of the LEGO Group, which does not sponsor or endorse this project. Bugs and ideas: [GitHub Issues](https://github.com/jakubmatisak/moje-kocky-desktop/issues).

A new version installs over the old one. Your data in `%APPDATA%\MojeKocky` stays, and before the first start of the new version the database is backed up into `%APPDATA%\MojeKocky\backups` ([how to restore a backup](https://github.com/jakubmatisak/moje-kocky-desktop#backup-on-update)). An older 0.1.x install, which was for one user only in `%LOCALAPPDATA%\Programs\MojeKocky`, is removed by the installer and your data is kept; if it is still running, the installer tells you to close Moje kocky and run it again.

The installer is not code-signed. When Windows says "Windows protected your PC", click **More info → Run anyway**. If Windows says it cannot access the file, your antivirus blocked the program: Windows Security → Protection history → Allow on device. Windows then asks whether to let the installer make changes to your device (the publisher shows as unknown), on a standard account together with an administrator's password.

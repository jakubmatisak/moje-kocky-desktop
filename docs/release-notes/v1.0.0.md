### Novinky

- **Inštalácia pre všetkých používateľov počítača.** Program je v `C:\Program Files\MojeKocky`, ikonu v ponuke Štart a na ploche má každý používateľ, údaje každý vlastné. Inštalátor si preto vypýta práva správcu.
- **Záloha pri každej aktualizácii.** Pred prvým štartom novej verzie, aj keď sa schéma databázy nemení, appka skopíruje databázu do `%APPDATA%\MojeKocky\backups`. Ostáva 5 posledných záloh, staršie sa mažú až po úspešnom štarte. Fotky v zálohe nie sú.
- **Keď aktualizácia zlyhá**, okno ukáže cestu k zálohe a postup návratu. Záloha spred aktualizácie sa nezmaže.
- **Figúrky zo sérií sú len vo Figúrkach.** Zberateľské minifigúrky aj blind-box série (napríklad Mighty Machines) už nie sú v Zbierke, tá ukazuje sety. Prehľad, export CSV a súpis počítajú všetko. Keď hľadanie v Zbierke nájde figúrku, appka odkáže do Figúrok. Nerozbalené sáčky, predané figúrky a obnova cien série sú v detaile série pod tlačidlom **Kusy série**.

- **Bez trhovej ceny pomlčka, nie 0 €**: v Prehľade, vo Výkonnosti, v súčtoch, v súpise, v exporte CSV aj pri predaji.
- **Verzia appky** je v Nastaveniach → Aplikácia (vidí ju správca, teda prvý účet) a v zozname aplikácií vo Windows.
- **Zásady súkromia** spomínajú zálohy. Po aktualizácii sa ukáže oznámenie o zmene zásad; zmizne, keď ho potvrdíš.

### What's new

- **Installs for every user of the PC.** The program lives in `C:\Program Files\MojeKocky`, every user gets the Start menu and desktop icon, and each has their own data. That is why the installer asks for administrator rights.
- **Backup on every update.** Before the first start of a new version, even when the database schema does not change, the app copies the database into `%APPDATA%\MojeKocky\backups`. The last 5 backups are kept; older ones are deleted only after a successful start. Photos are not part of the backup.
- **If an update fails**, a window shows the path to the backup and how to go back (the message is in Slovak). The pre-update backup is not deleted.
- **Series figures live only under Minifigures.** Collectible minifigures and blind-box series (Mighty Machines, for example) are no longer in the Collection, which shows sets. The Overview, the CSV export and the insurance inventory count everything. When a search in the Collection matches a figure, the app points you to Minifigures. Sealed bags, sold figures and the series price refresh are on the series page under **Series pieces**.
- **Categories when editing a copy too**: pick or create them, not only when adding a set.
- **No market price means a dash, not 0 €**: in the Overview, Performance, totals, the insurance inventory, the CSV export and when selling.
- **The app version** is shown in Settings → Application (visible to the administrator, i.e. the first account) and in the Windows list of installed apps.
- **The privacy policy** now mentions the backups. After the update a notice about the changed policy is shown until you confirm it.

### Installing and updating

The installer is not code-signed. When Windows says "Windows protected your PC", click **More info → Run anyway**. If Windows says it cannot access the file, your antivirus blocked the program: Windows Security → Protection history → Allow on device.

Then the installer asks for administrator rights: Windows asks whether to let it make changes to your device (the publisher shows as unknown because the installer is not signed), and on a standard account it also asks for an administrator's password. The program goes into `C:\Program Files\MojeKocky` for every user of the PC; each user has their own data in `%APPDATA%\MojeKocky`.

**From an older 0.1.x version**, which was installed for one user only in `%LOCALAPPDATA%\Programs\MojeKocky`: the installer removes it itself (program, shortcuts and the entry in the list of apps) and leaves your data in `%APPDATA%\MojeKocky` alone; the database is backed up before the new version first starts. If the old version is still running, the installer tells you (in Slovak) to close Moje kocky and run it again, and changes nothing. A taskbar pin needs to be pinned again. Only the old install of the account the installer runs as is removed; if another user of the PC also had 0.1.x (or you enter the password of a different administrator account on a standard account), that user uninstalls it in Settings → Apps and declines deleting the data.

**Restoring a backup:** close the app, delete `lego.db-journal`, `lego.db-wal` and `lego.db-shm` in `%APPDATA%\MojeKocky` (if they are there) and copy the backup from `backups\` over `lego.db`. If the update failed, install the previous version from Releases; before going back to 0.1.x, uninstall 1.0.0 first (decline deleting the data). Details in the [README](https://github.com/jakubmatisak/moje-kocky-desktop#backup-on-update).

### What's new

- **Set photos can be enlarged.** On the set cards in the Collection and the Wishlist and on the set page, a magnifier sits in the bottom right corner of the photo. Clicking it opens the photo full size, and you can page on to the Brickset photos. The set page does not open.
- **The gallery on the set page** starts with the main photo and continues with the Brickset photos in the same window.

### Installing and updating

The installer is not code-signed. When Windows says "Windows protected your PC", click **More info → Run anyway**, then allow the changes to your device. The installer asks for administrator rights, and on a standard account also for an administrator's password. If Windows says it cannot access the file, your antivirus blocked the program: Windows Security → Protection history → Allow on device.

From an older 0.1.x version the installer removes the old install itself and keeps your data; details in the [1.0.0 notes](https://github.com/jakubmatisak/moje-kocky-desktop/releases/tag/v1.0.0).

**Restoring a backup:** close the app, delete `lego.db-journal`, `lego.db-wal` and `lego.db-shm` in `%APPDATA%\MojeKocky` (if they are there) and copy the backup from `backups\` over `lego.db`. Details in the [README](https://github.com/jakubmatisak/moje-kocky-desktop#backup-on-update).
